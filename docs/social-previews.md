# Social-card demos

`/test` contains local social-card demo endpoints for reviewing card rendering and
responsive crops. They are examples for an individual widget; they do not replace
site-wide Open Graph metadata or alter existing page metadata.

Keep a demo self-contained, use the established theme tokens, and label any
platform-shaped crop as an approximation. Do not claim that it reproduces a
particular social network's UI or card rules without direct verification.
